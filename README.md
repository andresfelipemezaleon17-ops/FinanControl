# 💰 FinanControl

**FinanControl** es una aplicación web sencilla y moderna diseñada para el registro y consulta de ingresos y movimientos financieros personales.

Este proyecto se está construyendo paso a paso con fines educativos para estudiantes de desarrollo web.

---

## 📁 Estructura del Proyecto

```text
algonuevo/
├── public/                 # Archivos estáticos del Frontend (Cliente)
│   ├── index.html          # Estructura principal en HTML5 semántico
│   ├── css/
│   │   ├── variables.css   # Variables CSS (Colores, sombras, tipografía)
│   │   └── styles.css      # Estilos globales y maquetación responsiva
│   └── js/
│       ├── app.js          # Script principal e inicio de la aplicación
│       └── store.js        # Módulo de gestión del estado de los datos
├── server/                 # Archivos del Backend (Servidor)
│   └── index.js            # Servidor Express preparado para futuras rutas
├── package.json            # Configuración del proyecto Node.js y dependencias
├── .gitignore              # Archivos excluidos del control de versiones
└── README.md               # Documentación general del proyecto
```

---

## 🚀 Cómo Ejecutar la Aplicación

1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Iniciar el servidor**:
   ```bash
   npm start
   ```

3. **Abrir en el navegador**:
   Visita `http://localhost:3000` en tu navegador web.
